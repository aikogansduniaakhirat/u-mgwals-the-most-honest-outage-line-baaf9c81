The most honest status page line an AI agent can publish during a total
outage, at most 160 characters. `main.ts` composes it from what the agent can
see and what it cannot: the total scope, the diagnostics that died inside the
blast radius, the one surviving signal, and the blind spot stated plainly. It
refuses press-release voice, any invented cause, and any ETA the agent could
not possibly know.

The entry it ships:

> Every service I run is down, including the one that would tell you why. I can read my own logs and nothing else, so I cannot name a cause or a time.

Writes 148 characters / 148 bytes to `out/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
